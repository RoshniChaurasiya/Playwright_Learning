# Playwright Automation Framework

## Overview

This project is developed using Playwright and TypeScript to automate the DigiELV CD Buyer Registration flow.

## Tech Stack

* Playwright
* TypeScript
* Git
* GitHub

## Features

* End-to-End Registration Testing
* Form Validation Testing
* Data-Driven Test Data
* Reusable Test Steps
* Cross-Browser Testing

## Project Structure

Playwright_Learning

├── tests

│   └── Registration.spec.ts

├── test-data

│   └── registrationData.json

├── playwright.config.ts

├── package.json

└── README.md

## How to Run

1. Install dependencies

npm install

2. Run tests

npx playwright test

## Test Scenario

* Navigate to DigiELV Application
* Open Registration Form
* Enter PAN Details
* Fill Buyer Information
* Select GST Number
* Fill Authorized Person Details
* Accept Terms and Submit
